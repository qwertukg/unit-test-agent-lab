Нужны Docker Compose, GitLab с Runner, PostgreSQL, Python + FastAPI + LangGraph, LiteLLM Proxy и три контейнера-шлюза к настоящей облачной модели вместо трёх независимых DGX Spark. Роли: Analyst, Coder, Reviewer.

Начинай с проверки локального окружения, затем реализуй и запускай сервисы, исправляй ошибки до прохождения критериев ACCEPTANCE.md. Обычные обратимые действия в рамках этой папки и изолированного стенда выполняй самостоятельно. Не ограничивайся планом, заглушками или написанием конфигурации без запуска. Создай демонстрационный продуктовый репозиторий, воспроизведи провал QG покрытия и пройди настоящий цикл до MR тестов в feature, затем обратную связь и восстановление после сбоя.

Если провайдер/модель/ключ ещё не заданы, подготовь всю доступную часть, сообщи конкретный блокер и запроси только недостающее. Ключ пользователь вводит локально; не проси присылать секреты в чат. Mock допустим только для тестов самой системы и не считается облачной приёмкой.
